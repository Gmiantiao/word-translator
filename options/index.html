1

创建 Notion Integration

前往 Notion 的 Integration 管理页面，创建一个新的 Integration：

打开 Notion Integrations →

点击「New integration」，名字随便填（如"划词翻译"），选择你的工作区，然后复制生成的 API Key。

2

新建一个页面并连接

在 Notion 里新建一个空白页面（随便叫什么，比如「面条捞词」），插件会在它下面建一个自己的数据库：

  1. 新建一个空白页面
  2. 点击右上角 ··· → Connections → Connect to
  3. 搜索并选择你刚创建的 Integration

不要把插件指向你自己已有的数据库。插件需要自己拥有表的列结构 —— 指向别人的库，它会往你的表里补列，或者把单词写进你别的列里。

3

填写配置

打开那个页面，URL 形如
https://notion.so/页面ID
直接粘贴完整 URL 即可，插件会自动提取 ID
